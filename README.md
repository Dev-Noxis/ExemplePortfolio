# Fil Rouge - Portfolio Photographe

Projet en HTML et CSS réalisé avec le protfolio fournis.

## Lien
GitHub Pages : https://dev-noxis.github.io/ExemplePortfolio/

## Consignes
- Du HTML et du CSS pas de javascript ou autre
- Le W3C est valide et en HTML et en CSS
- Google Fonts : Yeseva One, Montserrat
- Font Awesome pour les icônes
- Lorem Picsum pour les images

## Responsive
- Mobile : 9 images affichées avec 3 colonnes
- Tablette : 15 images affichées avec 5 colonnes
- Desktop : 15 images affichées avec 4 colonnes
